# maragroups-website

A sanitized rebuild of a small-business site layout I designed and shipped end-to-end (based on real client work at maragroups.com). No client copy, images, or branding here — just the clean, responsive layout pattern: sticky nav, hero, services grid, contact section, mobile menu.

## Run it

Open `index.html` in a browser — no build step, no dependencies.

## What's demonstrated

- Semantic HTML5 layout
- Responsive CSS (grid + flexbox, one breakpoint)
- Vanilla JS mobile nav toggle and smooth scrolling
- Contact form with client-side validation (front-end only)
